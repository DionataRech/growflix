Growflix
Growflix é uma aplicação web inspirada no estilo da Netflix, criada com HTML5, CSS3 e Bootstrap. O site foi desenvolvido para simular uma plataforma de streaming, apresentando uma interface visualmente atraente e responsiva.



🔗 URL do Projeto
Acesse o site ao vivo: Growflix Project

📜 Descrição
O Growflix é um projeto voltado para a prática de desenvolvimento front-end, utilizando o framework Bootstrap para criar um layout responsivo e organizado. O site exibe uma lista de filmes com seções destacadas, como "Em Destaque" e "Categorias Populares", imitando a interface de grandes plataformas de streaming.

🚀 Funcionalidades
Layout Responsivo: Desenvolvido com Bootstrap, o site se adapta a diferentes tamanhos de tela.
Interface Moderna: Design simples e eficiente, inspirado na Netflix, para uma experiência de usuário atraente.
Navegação Simples: O site inclui uma barra de navegação fixa para facilitar a usabilidade.
💻 Tecnologias Utilizadas
HTML5: Estruturação do conteúdo do site.
CSS3: Estilização personalizada, alinhada com o design da Netflix.
Bootstrap: Framework CSS utilizado para tornar o site responsivo e melhorar o layout.
